## 1. 这是什么

### 1.1 一句话

这是一个**手套工厂生产管理系统（MES）的网页原型**：它把“客户下单 → 安排产线 → 车间生产 → 成品入库”这条完整链路，做成了可以点、可以查、可以改的网页。

### 1.2 什么是 MES

MES 是 Manufacturing Execution System（制造执行系统）的缩写，可以理解为**车间里的“调度台 + 记账本”**：

- ERP 管的是“公司层面的账”：客户、订单金额、采购、财务。
- MES 管的是“车间层面的事”：这张订单排在哪条产线、今天生产了多少只、用掉了哪一批原料、哪台设备报警了、成品入了哪个库位。

没有 MES 时，这些信息通常散落在纸质流转单、Excel 和班组长的记忆里，出现交付异常时很难倒查。MES 的核心价值就是**把每一步都记下来，并且能互相追溯**。

### 1.3 这个原型的边界（重要）

- 它**没有后端和数据库**。所有数据是内置的样例数据，保存在你自己的浏览器里。
- 它**没有登录和权限**，固定以“张伟 / 生产计划员”的身份展示。
- 它的作用是：让业务方直观看到“系统做出来大概长什么样、怎么操作”，用于需求沟通和确认，而不是上线使用。

所以你可以**放心地随便点、随便改、随便删**——数据只影响你这台电脑的这个浏览器，出问题用菜单里的“重置样例数据”一键还原。

## 2. 先理解业务：手套是怎么生产出来的

原型里的样例是**唯律**这家工厂，生产丁腈手套和乳胶手套。理解下面这条链路，页面上 90% 的名词就都能看懂了：

```
① 客户下单            华东医疗要 10 万只黑色 M 码丁腈手套，9 月 10 日前交货
        ↓
② 确认产品和包装      查产品库：这款手套用什么配方、什么工艺、装几只一盒
        ↓
③ 检查库存能不能做    仓库里的丁腈胶乳、硫磺、纸盒够不够（叫"齐套检查"）
        ↓
④ 人工排产            计划员把 10 万只拆开：包装线 01 做 6 万，包装线 02 做 4 万
        ↓
⑤ 下发生产任务        每条产线拿到一张"生产任务"，写明做什么、做多少
        ↓
⑥ 车间生产 + 报工     班组每天上报：今天完成了 4.5 万只
        ↓
⑦ 领料与耗用          生产用掉了 NBR260820A 这一批胶乳 189 公斤，从库存里扣掉
        ↓
⑧ 成品入库            做好的产品进入成品仓 FG-A01 库位，形成批次 FG260831A
        ↓
⑨ 出货 / 追溯         将来客户反馈异常，可以从成品批次一路倒查回原料批次和设备数据
```

与此同时还有一条**设备数据线**：车间设备（浸渍机、点数机、包装机）把温度、产量、报警通过 PLC 上传到“中控”，中控再通过接口推送给 MES，于是页面上能看到实时曲线和报警记录。

> 另外有一类订单叫**库存订单**：不是客户下的单，而是工厂自己为了备货而生产，编号以 `IO` 开头。它不需要客户和专用包材，其余流程一样。

## 3. 启动与打开

### 3.1 环境要求

| 项目 | 要求 |
| --- | --- |
| Node.js | 20.19 或更高（推荐 22.12+，Vite 8 的要求） |
| 浏览器 | Chrome / Edge 等现代浏览器 |
| 屏幕 | 页面按桌面端设计，最小宽度 1180 像素；**不适配手机** |

### 3.2 本地启动（开发预览）

在本文件所在目录 `weilu_MES/web_example/WEILU_example` 下执行：

```bash
npm install
```

```bash
npm run dev
```

终端会打印一个地址（通常是 `http://localhost:5173`），在浏览器里打开即可。修改代码会自动刷新页面。

### 3.3 打包成静态文件

```bash
npm run build
```

产物在 `dist/` 目录，是纯静态文件，可以直接丢到任意 Web 服务器或用 `npm run preview` 本地查看。

### 4.1 左侧导航

八个导航入口，点一下就切换。数字角标（③②）表示该模块有待处理事项。最底部显示系统状态和原型版本号。

### 4.2 顶部栏

| 元素 | 作用 |
| --- | --- |
| 面包屑 + 标题 | 当前位置，如“唯律制造工厂 / 订单管理” |
| 搜索框 | 过滤**当前页签**表格里的数据；按 `Ctrl + K`（Mac 是 `⌘ + K`）可直接聚焦 |
| 🔔 通知按钮 | 红点表示有未读。点开是设备报警、接口异常、待审报工等列表，**点任一条会直接跳到对应记录** |
| 用户卡片 | 点开显示当前身份、原型数据保存状态，并提供“重置样例数据”等操作 |

### 4.3 主内容区

- **运营总览**是一个驾驶舱页面（详见 6.1）。
- **其余七个模块**结构完全一致：模块头 → 四个指标卡 → 数据面板（页签 / 过滤条 / 可选的图表 / 表格 / 分页）。学会一个就等于学会全部。

## 5. 十分钟上手演练（按顺序做一遍）

跟着做完这 10 步，你就用过了这个原型的所有功能。

### 第 1 步 · 从驾驶舱开始

打开页面，默认在**运营总览**。看三块内容：

- **订单生产链路**：从“订单审核”到“成品入库”的五个环节，每个环节下面是今日数量。**点任一个环节**会跳到对应模块（例如点“生产执行”跳到生产执行的生产任务）。
- **待办与预警**：三条最要紧的事。**点第一条“销售订单临近交期”**。

### 第 2 步 · 跳转与高亮

页面跳到了**订单管理 → 销售订单**，并且 `SO20260831001` 那一行是**淡黄色高亮**的——这就是刚才那条待办说的订单。

> 高亮的意思永远是“这条是你刚才要找的 / 刚才操作的记录”。

### 第 3 步 · 看详情

点击这一行任意位置（或行尾的“查看 ›”），右侧滑出**详情抽屉**：上方是业务主键和状态，中间是全部字段，底部是“关联与追溯”。

### 第 4 步 · 追溯整条业务链路 ⭐

在抽屉底部点 **“查看完整业务链路 →”**，弹出全屏的链路视图：

```
① 销售订单 → ② 包装信息 → ③ 待排订单 → ④ 排产计划 → ⑤ 产线分配 → ⑥ 排产甘特图
→ ⑦ 生产任务 → ⑧ 生产组织 → ⑨ 原料耗用 → ⑩ 生产报工 → ⑪ 成品入库
→ ⑫ 出入库记录 → ⑬ 原料库存 → ⑭ 包材库存 → ⑮ 成品库存 → ⑯ 库存总览
```

这不是画上去的图，而是系统**扫描全部模块数据、按编号引用关系自动算出来的**：订单号 `SO20260831001` 出现在排产计划里，排产号出现在产线分配里，任务号出现在报工和耗用里，批次号 `FG260831A` 出现在入库和库存里……于是串成一条链。

每张卡片下方有“在 XX 中查看 →”。**点“在生产任务中查看”**，弹窗关闭并跳到生产执行 → 生产任务，`PT20260901001` 高亮。这就是 MES 说的“可追溯”。

### 第 5 步 · 新建一条记录

回到**订单管理**，点右上角 **＋ 新建销售订单**：

1. “业务编号”是灰色只读的，已按 `前缀 + 日期 + 流水` 自动生成（如 `SO20260901-001`）。
2. 带红色 `*` 的是必填项。先什么都不填直接点“保存记录”，顶部会出现红框提示“客户为必填项 / 产品为必填项”。
3. 填好客户、产品等信息后点“保存记录”。抽屉关闭，右下角出现提示，新记录出现在**表格第一行并高亮**。

> 保存后如果表格正在筛选状态，筛选会自动清空，确保你能看见刚存的记录。

### 第 6 步 · 编辑与批量操作

- **编辑**：点开任意记录详情 → 右上角 **✎ 编辑** → 改字段或状态 → “保存修改”。
- **批量**：勾选表格左侧复选框（表头复选框可全选当前页），上方出现蓝色批量条：
  - “导出所选”：只导出勾中的记录；
  - “批量状态”下拉：把选中的记录状态一次性改掉；
  - “移除所选”：二次确认后删除；
  - “取消选择”。

### 第 7 步 · 查询、筛选、分页、导出

在**订单管理 → 销售订单**试一遍：

1. 表格上方搜索框输入 `华东` → 只剩华东医疗的订单。清空恢复。
2. 状态下拉选“生产中” → 只看在产订单。
3. 点 **筛选条件 ＋** 打开高级筛选：选择“客户 / 包含 / 华东”，可点“＋ 增加条件”叠加多个条件（条件之间是“并且”），点“应用筛选”。生效后按钮上会显示条件数量，下方出现可单独删除的条件标签。
4. 底部“每页”改成 20/50，或点页码翻页。
5. 点右上角 **⇩ 导出 CSV**，浏览器下载一个 CSV 文件，导出的是**当前筛选后的全部结果**（不是只有当前页），Excel 打开不乱码。

### 第 8 步 · 导入 CSV

点右上角 **⇧ 导入**：

1. 先点“⇩ 下载导入模板”，得到与当前页签列完全一致的模板文件。
2. 用 Excel 填几行，保存为 CSV。
3. 回到抽屉点“选择 CSV 文件”。系统立刻逐行校验并给出结果，例如：

   | 行 | 结果 |
   | --- | --- |
   | 第 2 行 | `SO20260901-001` 校验通过（编号列留空会自动补号） |
   | 第 3 行 | 编号 `SO20260831001` 已存在 |
   | 第 4 行 | 客户为空 |

4. 顶部汇总“可导入 1 行 / 错误 2 行”。点“导入有效行”：**正确的行照常导入，错误行被跳过**，不会因为一行错就整份失败。

### 第 9 步 · 三个专用视图

- **人工排产 → 排产甘特图**：横轴是日期，每条产线一行泳道，色块是一段排产计划，块内浅色填充是完成进度，红色竖线是今天。**按住色块左右拖动可以整体改期**，松手后下方表格的“计划开始 / 计划结束”同步更新。
- **设备管理 → 组织层级**（或生产执行 → 生产组织）：工厂 → 车间 → 产线 → 设备的树，`▾ / ▸` 展开收起；**点节点名可筛选下方表格**；鼠标移到节点上会出现 `＋`（新增子节点）、`✎`（重命名）、`×`（删除）。
- **设备管理 → 实时状态**：设备采集曲线。上方按钮切换设备点位；绿色横带是标准范围，超出范围的点会变红并提示“超出标准范围”；点“开启模拟推送”后每 3 秒生成一个新数据点，用于演示实时刷新（**是模拟数据，不是真实设备数据**）。

### 第 10 步 · 通知与数据重置

- 点顶部 🔔：看报警/预警/待办，点任一条跳转，也可“全部标记已读”。
- 点右上角用户卡片：可以看到“原型数据：已保存在本机浏览器 / 最近保存时间”，点 **“重置样例数据”**（二次确认）即可把你这一路的新增、编辑、导入、删除、改期全部还原成初始样例。

## 6. 九个模块分别能做什么

### 6.1 运营总览（驾驶舱）

给管理者看的首页。四个 KPI（今日计划产量、今日已完成、在制订单、设备综合效率）、订单生产链路、待办与预警、产线实时进度。**页面上几乎每一块都可以点进去看明细**。

### 6.2 订单管理 `O-01 — O-07`

| 页签 | 内容 | 通俗解释 |
| --- | --- | --- |
| 销售订单 | 客户、产品、数量、交期、优先级、状态 | 客户下的单 |
| 库存订单 | 产品、备货数量、目标仓库、备货原因 | 工厂自己备货的单 |
| 包装信息 | 纸盒、纸箱、每盒数量、每箱盒数、喷码内容 | 这批货怎么装、箱子上印什么 |
| 终止记录 | 终止原因、资源释放情况、申请人 | 订单中途取消的登记 |

### 6.3 人工排产 `S-01 — S-02`

| 页签 | 内容 | 通俗解释 |
| --- | --- | --- |
| 待排订单 | 剩余待排数量、齐套情况 | 还没安排产线的订单，以及料够不够 |
| 排产计划 | 分配产线、计划数量、计划周期 | 计划员做的生产安排 |
| 产线分配 | 排产号 → 产线 → 数量 → 生成的任务号 | 一张计划拆到具体产线的明细 |
| 排产甘特图 | 时间轴视图，可拖拽改期 | 用图看“谁在什么时候做什么” |

### 6.4 生产执行 `PR-01 — PR-07`

| 页签 | 内容 | 通俗解释 |
| --- | --- | --- |
| 生产任务 | 计划数量、累计报工、完成率、预计结束 | 每条产线手上的活 |
| 生产报工 | 生产任务、生产批次、报工总数、报工时间 | 班组上报今天做了多少 |
| 原料耗用 | 任务、物料、批次、耗用数量 | 这活用掉了哪批料、用了多少 |
| 成品入库 | 生产批次、入库数量、库位、单据状态 | 做好的货进仓库 |
| 生产组织 | 工厂—车间—产线树 + 产线运营列表 | 按组织层级看生产情况 |

### 6.5 仓库管理 `W-01 — W-09`

| 页签 | 内容 | 通俗解释 |
| --- | --- | --- |
| 库存总览 | 全部物料与成品的库存、可用量、占用量 | 仓库总账 |
| 原料库存 | 批次、生产日期、有效期、库存状态 | 胶乳、硫磺、氧化锌等 |
| 包材库存 | 批次、专用客户、专用订单 | 纸盒、纸箱、喷码碳带 |
| 成品库存 | 生产批次、来源任务、来源类型 | 做好的手套 |
| 入出库记录 | 单据类型、数量（带 +/-）、来源单据 | 每一次进出仓的流水 |

> **库存数量 / 可用数量 / 占用数量**：可用 = 库存 − 占用。已被订单“预定”的部分算占用，不能再分给别的订单。

### 6.6 产品库 `P-01 — P-08`

产品的“说明书中心”：产品档案（编号、规格、版本）、产品特性（颜色/尺码/克重/长度/拉力）、工艺参数（工序、标准值、上下限）、物料配方（每只手套用多少克胶乳、损耗率）、版本记录（改了什么、什么时候生效）。

### 6.7 设备管理 `EQ-01 — EQ-08`

设备台账（编号、类别、型号、所属产线、责任人、数据新鲜度）、组织层级树、实时状态曲线、报警记录（报警代码、级别、起止时间）、采集数据（点位编码、采集值、单位、频率、采集状态）。

### 6.8 接口中心 `I-01 — I-02`

MES 与中控之间的“通信管理”：接口清单（方向、方式、频率、最近通信）、点位映射（PLC 点位 ↔ 业务字段）、接收日志（每条报文的大小、耗时、重试次数）、异常日志（错误码、原因、处理状态）。

## 7. 通用操作详解

八个业务模块的操作方式完全一致，这里集中说明。

### 7.1 找数据的四种方式

| 方式 | 位置 | 特点 |
| --- | --- | --- |
| 顶部搜索 / 表格搜索 | 顶栏、过滤条左侧 | 在当前页签所有列里做关键字模糊匹配 |
| 状态下拉 | 过滤条 | 快速按状态过滤，选项随页签自动变化 |
| 高级筛选 | 过滤条“筛选条件” | 任意列 × 包含 / 等于 / 不包含 / 为空，多条件叠加（并且） |
| 组织树节点 | 树视图页签 | 点节点筛选下方表格，可“清除节点筛选” |

四种方式可以叠加使用，右侧“共 N 条记录 · 第 x / y 页”会实时变化。

### 7.2 表格与分页

- 点行任意位置 = 打开详情；点复选框列不会打开详情。
- 底部可切换每页 10 / 20 / 50 条，首尾页时 `‹ ›` 自动置灰。
- 淡黄色高亮 = 刚刚新增、导入、编辑或跳转定位到的记录。

### 7.3 新增 / 编辑 / 删除

| 操作 | 入口 | 说明 |
| --- | --- | --- |
| 新增 | 模块右上角 `＋ …` | 按钮文字随当前页签变化（在“生产报工”页签上就是“＋ 生产报工”）；编号自动生成；必填校验 |
| 编辑 | 详情抽屉 `✎ 编辑` | 编号不可改，其余字段和状态可改 |
| 删除 | 勾选后“移除所选” | 二次确认；只影响本地原型数据 |

### 7.4 导入与导出

- **导出**：导出当前筛选结果；批量条里的“导出所选”只导出勾选项。文件为 UTF-8 BOM 的 CSV，Excel 直接打开不乱码。
- **导入**：模板 → 填写 → 选择文件 → 逐行校验 → 导入有效行。校验包括表头是否匹配、必填是否为空、编号是否与已有数据或文件内部重复。

### 7.5 键盘与提示

- `Ctrl / ⌘ + K`：聚焦顶部搜索框；`Esc`：关闭顶部弹出菜单。
- 每次导入、导出、保存、编辑、批量更新、删除、甘特改期、组织树调整，右下角都会出现一条**深色提示条**，2～3 秒后自动消失。

## 8. 数据保存在哪里

- 所有改动保存在**你当前浏览器的 localStorage**（键名 `weilu-mes-prototype`），刷新页面不会丢。
- 数据**不会上传服务器**，也不会同步到别人的电脑；换浏览器、换电脑、用无痕窗口都会看到初始样例数据。
- 用户菜单 → **重置样例数据**：清空本地改动，回到初始状态。
- 如果代码里的样例数据被更新过，旧的本地存档会自动失效并加载新的初始数据（避免看到过期样例）。

## 11. 名词解释

| 名词 | 解释 |
| --- | --- |
| **MES** | 制造执行系统，管车间生产执行的系统 |
| **排产** | 把订单安排到具体产线和时间段 |
| **齐套** | 生产这张订单需要的原料、包材是否都够 |
| **生产任务（工单）** | 下发到某条产线的一份活，写明产品、数量、周期 |
| **报工** | 班组上报“这段时间完成了多少” |
| **批次** | 同一次生产或同一次到货的一批货，追溯的最小单位 |
| **过账** | 单据审核通过后正式影响库存（原型只展示状态，不做真实扣减） |
| **可用 / 占用数量** | 占用是被订单预定的部分；可用 = 库存 − 占用 |
| **FIFO** | 先进先出，优先使用最早入库的批次 |
| **浸渍线 / 包装线** | 手套成型（把模具浸入胶乳）的产线 / 点数装盒装箱的产线 |
| **点数机** | 自动清点手套数量的设备，其计数值是产量数据来源 |
| **PLC / 中控** | 设备控制器 / 车间集中控制系统，设备数据经它们上传给 MES |
| **点位** | 一个具体的数据采集项，如“胶槽温度”对应点位 `PLC_D01_TEMP` |
| **数据新鲜度** | 距离上次收到该设备数据过了多久，用来判断通信是否中断 |
| **追溯** | 从任一环节双向查出完整链路：成品 → 原料，或订单 → 成品 |

## 12. 常见问题

**Q：我把数据改乱了 / 删错了怎么办？**
A：右上角用户卡片 → “重置样例数据” → 确认，一切回到初始状态。

**Q：导出的 CSV 用 Excel 打开是乱码吗？**
A：不会。导出文件带 UTF-8 BOM，Excel 可直接打开。

**Q：导入时提示“表头与当前页签的列名不匹配”？**
A：请先在同一个页签点“下载导入模板”，用该模板填写。不同页签的列不同，模板不通用。

**Q：为什么“切换角色 / 权限”点了只弹出一句提示？**
A：登录、角色和权限需要后端支持，原型无法真实实现，因此只做说明而不是假装可用。同类情况还有真实的 Excel 模板导入、状态流转校验、库存事务等，详见 [TODO.md](./TODO.md)。

**Q：设备实时曲线是真的实时数据吗？**
A：不是。曲线是内置的样例数据；点“开启模拟推送”后每 3 秒生成的新点也是本地模拟，用来演示刷新效果，未接入任何 PLC 或中控接口。

**Q：追溯链路是提前画好的吗？**
A：不是。系统会扫描全部模块数据，按订单号、排产号、任务号、批次号、报文号、设备编码之间的引用关系自动串联，再按业务阶段排序展示。你新增的记录只要用了相同的编号，也会自动出现在链路中。

**Q：为什么手机上打开很难用？**
A：这是面向车间办公电脑设计的桌面端页面，最小宽度 1180 像素，暂不适配移动端。

**Q：这个原型可以直接给客户当系统用吗？**
A：不可以。它没有后端、数据库、权限和事务，仅用于需求沟通与交互确认。功能边界、覆盖情况和待确认事项都记录在 [TODO.md](./TODO.md)。
