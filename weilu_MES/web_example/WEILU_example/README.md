# 唯律 MES 一期 Web 参考原型说明

## 1. 原型定位

本项目依据 `weilu_MES/requirement.md` 建立，是一个使用 Vue 3、TypeScript 和 Vite 编写的传统 MES Web 页面参考原型。

原型用于展示唯律 MES 一期可能采用的导航结构、驾驶舱、业务列表、查询与筛选方式、增删改与导入导出交互、排产甘特图、组织层级树、设备实时曲线，以及按业务编号自动关联的追溯链路。它不是可上线的 MES，也不代表需求已经开发完成或通过验收。

本文中的状态含义如下：

- **已展示**：已有对应导航、页面、页签、字段或样例数据。
- **原型交互**：前端可以点击、查询、筛选、分页、导入、导出、保存、编辑、删除或追溯，数据保存在浏览器本地。
- **未实现**：需要后端、数据库、权限、事务或真实接口服务，当前原型不提供。
- **待确认**：需求文档没有给出最终规则，正式开发前需由客户确认。

## 2. 当前页面组成

- 运营总览：生产指标、订单生产链路、待办预警和产线进度；链路节点、待办项与产线行均可跳转到对应模块记录。
- 订单管理：销售订单、库存订单、包装信息和终止记录。
- 人工排产：待排订单、排产计划、产线分配和排产甘特图（可拖拽改期）。
- 生产执行：生产任务、生产报工、原料耗用、成品入库和生产组织（工厂—车间—产线树）。
- 仓库管理：库存总览、原料库存、包材库存、成品库存和入出库记录。
- 产品库：产品档案、产品特性、工艺参数、物料配方和版本记录。
- 品质管理：待检任务、原料检验、过程检验、成品检验和质量处置。
- 设备管理：设备台账、组织层级（工厂—车间—产线—设备树）、实时状态（采集曲线）、报警记录和采集数据。
- 接口中心：接口清单、点位映射、接收日志和异常日志。

每个页签都有独立的列定义和样例数据。页面使用唯律手套生产样例，`SO20260831001`、`PACK20260831001`、`SCH20260901001`、`ALLOC20260901001`、`PT20260901001`、`USE20260901001`、`REPORT20260901001`、`FQC20260831018`、`FGIN20260901001`、`FG260831A`、`INV-FG-001` 等编号在各模块之间真实互相引用，追溯链路即由这些引用关系自动生成。

## 3. 当前可操作范围

### 3.1 查询与筛选

- 左侧导航切换模块，模块内页签切换对应表格与数据。
- 顶部搜索、表格搜索、状态下拉框可过滤当前页签数据；`Ctrl / ⌘ + K` 聚焦顶部搜索框。
- “筛选条件”打开高级筛选面板：可按任意列组合多个条件（包含、等于、不包含、为空），条件以标签展示并可单独移除或清空。
- 表格分页支持页码切换与每页条数（10 / 20 / 50），并显示当前区间与总条数。
- 组织树节点可筛选下方表格数据，并可一键清除节点筛选。

### 3.2 数据维护

- 模块主按钮按当前页签打开新增表单：编号按“前缀 + 日期 + 流水”自动生成并避开已有编号，必填项校验不通过时给出错误提示，保存后写入数据并在表格首行高亮。
- 详情抽屉可切换到编辑模式：修改字段与状态后保存，表格、搜索、筛选和导出同步更新。
- 行复选框与表头复选框（含半选状态）支持批量操作：导出所选、批量更新状态、移除所选（二次确认）、取消选择。
- “导入”抽屉支持 CSV 导入：可下载与当前页签列一致的模板，导入时逐行校验必填项、编号重复（与已有数据及文件内部）与表头匹配，错误行列出原因并跳过，正确行照常导入，未填编号的行自动补号。
- “导出 CSV”按当前筛选结果导出带 UTF-8 BOM 的 CSV，Excel 直接打开不乱码。
- 全部改动（新增、编辑、导入、批量更新、删除、甘特改期、组织树调整）保存在浏览器 localStorage，刷新后保留；用户菜单中的“重置样例数据”可回到初始状态。样例数据升级后旧存档会自动失效并回到新的初始数据。

### 3.3 可视化与追溯

- 排产甘特图按计划开始与结束日期绘制产线泳道、进度填充与当日标记；左右拖拽甘特条可整体改期，松开后写回计划开始与结束日期。
- 生产组织与设备组织层级为可展开、收起的树，节点支持新增子节点、重命名和删除。
- 设备实时状态提供采集曲线：可切换设备点位，显示标准范围带与超限标记，并可开启 3 秒一次的模拟推送演示实时刷新。
- 详情抽屉的“查看完整业务链路”打开追溯视图：系统扫描全部模块数据，按订单号、排产号、分配号、任务号、批次号、报文号与设备编码逐层关联，再按业务阶段排序展示（销售订单 → 包装要求 → 待排订单 → 排产计划 → 产线分配 → 甘特计划 → 生产任务 → 生产组织 → 原料耗用 → 生产报工 → 检验 → 成品入库 → 出入库记录 → 库存）；点击任一节点跳转到对应模块页签并定位高亮该记录。

### 3.4 顶部与提示

- 通知按钮打开通知与报警列表（设备报警、接口异常、待审报工、待判定批次），点击可跳转到对应记录，并可标记已读。
- 用户菜单显示当前原型数据的保存状态与最近保存时间，提供重置样例数据、角色权限说明与原型信息。
- 导入、导出、保存、编辑、批量更新、删除、改期、组织树调整均有右下角操作提示。

### 3.5 仍需后端或现场条件的部分

以下内容前端无法自行完成，原型中以明确的提示或占位表达：

- 用户登录、角色权限、数据范围与审批流：用户菜单固定为“生产计划员”视角，点击“切换角色 / 权限”会说明该能力需后端实现。
- 服务端编号服务、并发唯一约束、数据库事务、库存占用与回滚。
- 真正的 Excel（.xlsx）模板导入导出与导出权限控制：原型提供的是 CSV 模板与 CSV 导出。
- 中控实时数据：实时曲线为样例数据与本地模拟推送，未接入 PLC / 中控接口。
- 审计日志与历史不可篡改：原型的编辑与删除直接覆盖本地数据，没有留痕。
- 状态流转校验：批量更新状态与编辑状态不做状态机校验，任何状态都可以改到任何状态。

## 5. 品质功能边界

品质管理导航包含待检任务、原料检验、过程检验、成品检验和质量处置，检验与处置记录已通过任务号、批次号接入追溯链路（例如 `IPQC20260901008` 烘箱温度超限与 `QC-ACTION20260901003` 批次暂扣关联到 `SO20260831002`）。

需求文档没有为品质模块提供独立功能编号和完整字段规则，以下能力不能视为已确定或已实现：

- 来料、过程、成品检验单的最终字段和审批流程。
- 抽样方案、AQL 自动判定、复检和让步接收。
- 冻结、解冻、放行和质量处置闭环。
- 品质统计报表与不合格趋势分析。

## 7. FIFO、库存占用与释放边界

原型显示批次号、库存数量、可用量、占用量和质量状态，但没有实现 FIFO 算法或库存事务。

正式应用建议按以下流程实现：

1. 排产或任务下发时，查询物料、仓库和库区下的候选批次。
2. 排除待检、冻结、不合格和可用数量为零的批次。
3. 对可用批次按确认后的日期字段升序排序，并从最早批次开始分配。
4. 单批不足时继续分配下一批；总量不足时整体失败并显示缺口。
5. 生成独立库存占用记录，保存订单、任务、物料、批次、数量、状态和时间。
6. 正式领料时将占用转为出库；取消排产、终止任务、冲销或超时后按规则释放。
7. 占用、释放、出库和回滚必须在数据库事务中执行，并使用锁或版本号防止并发超占。

最早批次不合格时是否自动跳批、具体排序日期、占用时点、超时释放和人工例外审批仍属于 C-04 待确认事项。

## 10. 技术说明

- 框架：Vue 3 + TypeScript + Vite，单页应用，不使用独立路由。
- 数据来源：前端硬编码样例；运行期数据在 `src/store.ts` 的内存表中，并同步到浏览器 localStorage（键 `weilu-mes-prototype`）。
- 无第三方 UI、图表或表格库：甘特图、组织树、采集曲线、追溯链路、CSV 解析与导出均为本项目实现。

目录结构：

```
src/
  App.vue                  外壳：侧边导航、顶栏、通知与用户菜单、追溯弹窗、提示信息
  types.ts                 列、行、页签、模块、树、曲线、追溯链路类型
  store.ts                 数据表与组织树：初始化、增删改、导入、编号生成、本地持久化与重置
  toast.ts                 操作提示
  utils/csv.ts             CSV 导出、导入模板与 CSV 解析
  data/
    helpers.ts             列与行的紧凑定义方式，并按列推导表单字段
    dashboard.ts           导航、KPI、链路节点、待办、通知和产线样例
    trace.ts               按业务编号自动构建追溯链路
    modules/*.ts           八个业务模块的页签、列与样例数据
  components/
    DashboardView.vue      运营总览
    ModuleView.vue         模块页：指标、页签、筛选、分页、批量、表格、抽屉
    FilterPanel.vue        高级筛选面板
    GanttChart.vue         排产甘特图（可拖拽改期）
    OrgTree.vue            组织层级树（可增改删节点）
    RealtimeChart.vue      设备采集曲线（含模拟推送）
    RecordDrawer.vue       记录详情与编辑抽屉
    CreateDrawer.vue       新增表单抽屉
    ImportDrawer.vue       CSV 导入与逐行校验抽屉
    TraceModal.vue         业务链路追溯
    ToastStack.vue         操作提示
  style.css                全局样式
```

本地运行：

```bash
npm install
npm run dev
```

正式构建：

```bash
npm run build
```
